## Agent skills

### Issue tracker

GitHub Issues on `LyleClassen/SyncBox`, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Canonical roles use the default label strings, except `ready-for-agent`, which is `agent-ready` (the label the coding-agent-loop daemon watches). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` at the repo root and ADRs in `docs/adr/`. See `docs/agents/domain.md`.
