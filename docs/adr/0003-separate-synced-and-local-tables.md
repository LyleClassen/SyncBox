# Store Rekordbox-copied data and SyncBox-only data in separate tables

mixxxa's Sync deleted and re-imported `content`. Its own columns (waveform peaks, analysis results) lived in the same table, so it had to save them before each Sync and restore them afterwards, and every new local column had to be added to that list by hand or it would be silently lost. In SyncBox, tables copied from Rekordbox (tracks, playlists, playlist entries, cues, artists, albums, keys) hold only Rekordbox data, and a Sync is free to replace them wholesale. Anything SyncBox computes lives in its own tables keyed by the Rekordbox Track id, and a Sync never touches those, apart from removing rows whose Track no longer exists in Rekordbox. This follows the same direction as mixxxa's ADR-0001 (per-engine analysis tables).
